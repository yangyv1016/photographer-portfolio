# 订阅、兑换码与容量

订阅功能同时适用于本地存储和 COS 存储。兑换只更新平台数据库中的权限、期限和容量，不迁移作品目录，也不更换账户 UUID。

## 套餐规则

| 套餐 | 价格 | 固定有效期 | 当前总存储额度 |
| --- | ---: | ---: | ---: |
| 月卡 | ¥8 | 30 天 | 5 GiB |
| 季卡 | ¥20 | 90 天 | 10 GiB |
| 年卡 | ¥88 | 365 天 | 20 GiB |

容量沿用项目的二进制计量：1 GiB = 1024³ 字节。照片、头像、两种封面和未完成上传均计入已用容量。

每个订阅兑换码包含发行时保存的套餐、有效天数和容量。码的“可兑换有效期”控制它最晚何时可以使用，与兑换后获得的订阅天数是两个独立设置。

## 生成与使用兑换码

管理员在工作台的兑换码管理中选择套餐、数量、码有效期和备注。完整码仅在生成时显示，请立即复制或下载保存；数据库保留哈希及使用记录，不提供恢复完整码的接口。

同一个码可以用于以下任一场景，每个码只能成功使用一次：

- 新用户在注册页填写邀请码／兑换码，注册成功时激活相应订阅。
- 老用户进入「订阅与容量」，输入兑换码，先预览套餐、容量及新到期时间，确认后续期。

续期后的到期时间为 `max(当前时间, 原到期时间) + 新卡固定天数`。跨套餐兑换时容量立即切换为新卡总额度，不累加。

例如，年卡用户尚未到期时兑换月卡，订阅期限在原到期时间后增加 30 天，容量立即切换为 5 GiB。如果已用容量超过 5 GiB，已有作品保留，需释放空间或兑换更高容量套餐后才能继续上传。确认页面会展示这个变化。

码的消费、订阅更新和兑换记录在同一 SQLite 事务中完成。刷新页面、重复提交或并发请求不会把同一个码兑换多次。

## 到期与提醒

订阅截止前 7 天，工作台顶部显示提示，并在每天首次进入时弹窗提醒。是否已经提醒由服务器记录，按北京时间的日期判断，多个标签页或浏览器不会重复领取同一天的提醒。

到期后：

- 公开主页和相册显示“本用户订阅已到期，请及时订阅”。
- 公开目录不继续展示该账户；公开媒体接口不再提供原图、缩略图、头像或封面。
- 照片及资料图片暂停上传，包括恢复分块和完成未结束的上传。
- 仍可登录工作台、兑换续期、管理及删除自己的内容、取消未完成任务和下载自己的原图。
- 文件和数据库保留，不自动删除，不把订阅到期改成管理员停用。

兑换有效订阅后恢复公开展示及上传；上传仍受当前套餐总额度约束。

## 升级已有部署

安装新版时自动追加订阅字段和兑换记录表。已有账户保持原来的长期权限，旧邀请码继续沿用既有注册规则；管理员免订阅。新发出的套餐码按上表执行。

长期账户主动兑换套餐码后会转为该套餐的有限期订阅，因此也必须经过兑换预览与确认。管理员不能消费订阅码，避免误用。

数据库快照包含订阅、兑换记录和每日提醒状态；原图仍须按所选存储方式单独备份。

## 爱发电对接范围

网站侧生成、注册和后台兑换不依赖爱发电认证，也不要求配置 API Token。完整码可先由管理员分发。

爱发电认证完成后，应把月、季、年三个独立方案的 `plan_id` 分别对应到本站套餐。API Token 仅保存在服务器的凭据配置中，不放入浏览器、源码或兑换码文本。

当前站内订阅期限为固定 30／90／365 天，不直接套用爱发电站内权益的日期计算。正式连接订单和自动发码时，还需核对多期购买、重复通知和退款的处理，不能仅凭页面跳转或前端金额激活权益。

爱发电接口说明见[官方 API 文档](https://ifdian.net/p/9c65d9cc617011ed81c352540025c377)。
