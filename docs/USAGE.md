# 使用指南

站点由公开作品页和登录后的工作台组成。摄影师各自管理自己的资料、作品、便签和配额；平台管理员另外管理邀请码和账户。

## 常用入口

| 地址 | 用途 |
| --- | --- |
| `/` | 摄影师目录，可按名称或主页 ID 搜索 |
| `/<主页ID>` | 个人作品页、照片墙、系列与便签 |
| `/<主页ID>/album` | 只读三列系列相册，默认打开第一个系列 |
| `/login` / `/register` | 登录 / 邀请码注册 |
| `/dashboard` | 作品管理、上传、系列、原图下载与拼图导出 |
| `/dashboard/album` | 当前账户的私有相册排序工作区 |
| `/dashboard/profile` | 个人资料、账户信息、密码与上传任务 |
| `/dashboard/notes` | 便签本 |
| `/admin` | 管理员平台概览 |
| `/admin/accounts` / `/admin/invitations` | 账户管理 / 邀请码 |

## 注册与个人资料

管理员先生成邀请码，摄影师打开 `/register`，填写邀请码、显示名称、登录 ID 和密码。一个邀请码只可成功注册一次；密码至少 12 个字符。注册时主页 ID 初始与登录 ID 相同，之后可分别调整。

在「个人资料」中设置姓名、站名、个性签名、个人简介、地区和目录可见性。地区是可选的自定义文字，显示在签名下方并带定位图标，不读取设备位置。

可分别上传头像、主页封面和摄影师目录卡片背景。封面与目录背景可调整取景位置；目录背景未单独设置时沿用主页封面，移除独立背景后恢复沿用。头像与名字、签名放在主页标题区域。

「公开展示文件名」默认关闭，避免访客悬停时显示文件名。开启后按当前资料设置展示。

登录 ID 与主页 ID 相互独立：

- 修改登录 ID 需要再次输入新 ID 并验证当前密码。成功后所有会话退出，使用新登录 ID 和原密码重新登录。
- 修改主页 ID 更新公开访问地址；旧主页 ID 作为原账户别名保留，既有链接仍可访问。
- 改名只更新索引，不改变账户标识、作品库存储 UUID 或图片目录。第一个管理员沿用兼容目录，其余账户使用 UUID 目录。

## 照片库、系列与照片墙

在「作品管理」点击「上传照片」，选择系列和文件。上传通过网站服务分块写入管理员配置的服务器本地存储或 COS 私有桶；两种模式的使用操作相同。作品标题、描述和系列可在上传后编辑；支持勾选多张照片批量移动或删除。

「系列管理」用于维护系列名称与说明。系列内第一张照片自动作为系列封面，在「相册排序」调整首张即可；删除仍有作品的系列时，需要选择作品移入的目标系列。

编辑照片中的「加入照片墙」控制该图是否出现在主页照片墙。关闭不会删除照片，仍可在所属系列的相册和后台找到。照片墙的播放 / 暂停按钮旁有「相册」，在新标签页打开该系列相册。

每个账户有自己的容量配额，默认 5 GiB。照片、头像、封面、独立目录背景和未完成上传共同计入容量。上传失败留下的任务可在个人资料页取消。管理员下调配额不会删除已有照片，但超过额度后无法继续上传。

## 完整相册与作品排序

公开相册只按系列展示，不提供混合全部照片的汇总页。固定三列，每个格子按当前照片的宽高统一容器比例，图片完整居中、四周留白。相册列表只加载缩略图，点击后才加载详情原图。访客、其他摄影师以及在公开页浏览的本人均无法排序。

调整顺序请进入工作台「作品管理 → 相册排序」，选择系列后点击「调整顺序」。编辑页只展示各个系列，不提供混合的「全部」筛选。可以：

- 拖动手柄，或使用键盘操作调整。
- 选中照片后前移、后移、置顶、置底，或输入目标位置。
- 反转当前顺序、还原本次调整，最后点击「保存顺序」。

保存后直接改变该系列的真实作品顺序，同步公开相册、照片墙和作品管理；系列第一张自动作为封面，其他系列保持不变。新照片追加到所属系列末尾；编辑期间照片集合发生变化时，请刷新后重新调整。升级不会用旧的独立相册顺序覆盖已有作品顺序。

## 看大图与下载

详情图先显示缩略图，原图加载完成后自动替换。手机可双指缩放，电脑可用滚轮缩放，范围为初始适屏尺寸的 1–8 倍。放大后拖动查看细节，双击或点击「还原」恢复；未放大时可单指横向滑动切图。切图、关闭或调整窗口后恢复初始缩放。

摄影师在自己的作品管理中使用「下载原图」。下载接口检查当前登录账户与作品归属，样例图不提供此入口。公开页限制常规右键保存、拖拽、长按菜单和保存快捷键；这些措施只减少随手保存，无法阻止截图或从网络请求中获取已展示图片。

## Markdown 便签

打开「便签本」新建或编辑便签，会在当前页面打开近全屏编辑器。工具栏提供标题、强调、列表、链接、代码和表格等格式，可直接输入 Markdown，桌面同时显示源码与预览，小屏可切换编辑 / 预览。

标题最多 80 字，正文最多 20000 字，每个账户最多 100 条。便签分为置顶和普通两组，置顶便签优先展示；每组可上移、下移、置底或指定位置，保存的顺序同步到公开主页。新建便签排在普通组首位，置顶或取消置顶后进入对应组首位。调整顺序不会改写正文的编辑时间。

仅工作台提供「导出图片」：可从便签卡片、工作台正文弹窗或编辑器导出 PNG。图片保留浅黄色纸张背景，按完整 Markdown 正文自动延展，不截取两行摘要；编辑器可直接导出未保存的草稿。缺失图片会提示重试，超长正文超过浏览器清晰成图范围时会提示拆分便签，不会截掉尾部。公开展示页不提供导出入口。

主页显示标题与置顶标志，点击标题在当前页面弹窗阅读，不打开新标签页；没有便签时隐藏顶部入口和底部区域。便签不足一屏时不滚动，较多时循环播放，悬停、聚焦或阅读时暂停。

可使用标题、列表、引用、代码块、表格与任务列表。原始 HTML 作为文字显示；危险协议链接不会启用。图片需使用本站已有图片地址或 `/assets/` 资源，外站和 COS 直链图片不会自动加载。便签正文保存在账户 SQLite 作品库，不作为图片对象存储，随作品库快照备份。

````markdown
## 最近想拍

- 动画相关
  - 伊蕾娜
  - 四月是你的谎言
- 游戏相关
  - 明日方舟：初雪、阿米娅

### 准备工作

- [ ] 确认服装与场地
- [ ] 整理参考图

> 拍摄前再核对天气和光线。
````

## 拼图编排与 ZIP 导出

1. 在作品管理勾选照片，点击「导出拼图」。
2. 设置「导出张数」与「每行照片」。例如 19 张照片导出 3 张拼图，会按当前编排依次分成 7、6、6 张照片；这里的导出张数是成品拼图数量。
3. 在「照片编排」查看「第 1 张拼图」「第 2 张拼图」等分组及各组照片数。组内列数跟随每行照片；未勾选的照片单独放在「未加入导出」。
4. 拖动或用前移、后移、置顶、置底、目标位置、键盘调整顺序。改变张数、勾选或跨组移动后重新均分；只影响本次导出，不改变已保存的相册、照片墙或封面。
5. 设置比例、完整保留 / 裁切、间距、底色及 JPG / PNG。在「成品预览」逐张核对；最大宽度位于高级设置，超出画布尺寸限制时降低分辨率以保持指定张数。
6. 点击「导出全部 N 张 · ZIP」，等待生成后一次下载完整 ZIP。文件按拼图序号命名，无需逐张点击下载。

编排与成品预览使用缩略图；点击实际导出后，才通过当前账户的受控接口读取原图并依次生成高清结果。生成期间保持页面开启；关闭弹窗会取消剩余任务，不下载半成品 ZIP。照片很多时需要足够的浏览器内存和等待时间，可减少单次选择数量或降低最大宽度。

## 平台管理员

「邀请码」可设置数量、有效期、新账户配额和备注，并撤销未使用的码。完整邀请码仅在生成时显示一次，数据库只保存哈希；请当场复制并通过合适方式交给使用者。

「账户管理」可分配容量、启停账户、移入回收站和恢复。停用会注销会话并隐藏公开页；回收站保留作品与登录 ID。平台资源概览显示服务器与进程指标，网卡流量是服务器累计收发量，不能代替 COS / CDN 的账单。

生产备份、凭据与恢复由服务器管理员按[部署指南](DEPLOYMENT.md)维护。
